# One Click Switcher

Простая утилита для Windows 11: переключатели и действия в один клик с панели задач или рабочего стола. Без значка в трее и без фоновых процессов: программа запускается по клику, делает своё дело и закрывается.

## Что умеет

- Bluetooth и Wi-Fi: включить или выключить
- Микрофон (все микрофоны сразу) и звук (устройство вывода по умолчанию)
- Блокировка и сон
- Выключение и перезагрузка с отсчётом 5 секунд, звуком и отменой (кнопка, Esc, клик по окну или повторный клик по значку)
- Статус: плашка с состоянием всех переключателей на 5 секунд, повторный клик по ярлыку закрывает её раньше

## Как это работает

Один файл OneClickSwitcher.exe и по одному ярлыку на каждую функцию. Функция задаётся параметром в ярлыке:

    OneClickSwitcher.exe --toggle bluetooth
    OneClickSwitcher.exe --toggle wifi
    OneClickSwitcher.exe --toggle mic
    OneClickSwitcher.exe --toggle sound
    OneClickSwitcher.exe --action lock
    OneClickSwitcher.exe --action sleep
    OneClickSwitcher.exe --action shutdown
    OneClickSwitcher.exe --action restart
    OneClickSwitcher.exe --status

С приставкой --test выключение и перезагрузка только показывают отсчёт, компьютер остаётся включённым.

Ярлык можно закрепить на панели задач. В Windows 11 пункт находится так: правая кнопка по ярлыку, затем "Показать дополнительные параметры", затем "Закрепить на панели задач". Для стабильных ярлыков рекомендуется выравнивание панели задач слева (Параметры панели задач, Поведение панели задач).

## Защита от двойного клика

Повторный запуск той же функции в течение времени двойного щелчка Windows (около полсекунды) игнорируется. У выключения и перезагрузки повторный клик по значку после этого времени отменяет отсчёт.

## Сборка

Нужен .NET 10 SDK. В папке проекта:

    dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true

Готовый файл появится в папке bin\Release\...\publish.

## Известные ограничения

- Если Bluetooth-гарнитура с микрофоном подключилась после нажатия, её микрофон останется включённым: отключаются микрофоны, активные в момент клика.
- Переключатель камеры в этой версии не реализован.
- На некоторых HDMI-мониторах звук может быть не слышен, особенно первая нота.
